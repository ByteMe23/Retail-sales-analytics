# Retail Sales Data Analytics 

## 📌 Overview

This repository showcases an end-to-end data analytics workflow applied to a Kaggle retail dataset. The project encompasses data acquisition, cleaning, storage, analysis, and visualization, culminating in interactive dashboards using Power BI. It demonstrates proficiency in Python, SQL, and business intelligence tools, making it suitable for showcasing in resumes or portfolios.

## 📓 Project Workflow

1. **Data Acquisition**

   * Utilized Python to download the dataset from Kaggle, ensuring automation and reproducibility.

2. **Data Cleaning & Preprocessing**

   * Employed Pandas for data wrangling tasks such as handling missing values, correcting data types, and feature engineering.

3. **Data Storage**

   * Imported the cleaned dataset into an MS SQL Server database, facilitating structured storage and efficient querying.

4. **Data Analysis**

   * Conducted SQL-based analyses to extract meaningful insights, focusing on key performance indicators (KPIs) relevant to retail operations.

5. **Data Visualization**

   * Developed interactive dashboards using Power BI to visualize sales trends, customer demographics, and product performance.

6. **Reporting**

   * Compiled findings into comprehensive reports, providing actionable insights for business decision-making.

## 🛠️ Technologies Used

* **Programming Languages**: Python (Pandas), SQL
* **Database**: MS SQL Server
* **Data Visualization**: Power BI
* **Data Source**: Kaggle Retail Dataset

## 📁 Repository Structure

```
Retail-sales-analytics/
│
├── DataSet/            # Raw and cleaned data files
├── Docs/               # Documentation files
├── Notebooks/          # Jupyter notebooks for data analysis
├── PowerBi-reports/    # Power BI dashboard files
└── Scripts/            # Python scripts for data processing
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/ByteMe23/Retail-sales-analytics.git
cd Retail-sales-analytics
```

2. Install necessary Python libraries:

```bash
pip install -r requirements.txt
```

3. Execute the Python scripts in the `Scripts/` directory to preprocess the data and load it into the MS SQL Server database.

4. Open the Power BI reports in the `PowerBi-reports/` directory to explore the interactive dashboards.
